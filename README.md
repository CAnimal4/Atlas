# App Hub

Static landing page for the learning-app collection. The current working name is **Atlas**.

## Overarching name options

The first round felt too “AI platform.” This second round aims for the simplicity of Claro and Vertex: familiar words, one word, and no forced education-tech ending.

- **Atlas** — still the strongest of the first round; broad, memorable, and naturally fits a collection of subjects.
- **Mosaic** — a collection of distinct pieces that belongs together; warm and visual.
- **North** — clear direction and orientation without sounding corporate.
- **Arc** — short and modern, with a sense of progress across subjects.
- **Field** — grounded, open-ended, and works for both academic and practical learning.
- **Common** — suggests a shared home for learning, though it is less distinctive.

Current recommendation: **Atlas**, with **Mosaic** as the best alternative.
